# InventoryHub — Full-Stack Inventory Management (MVC + Web API + SignalR)

Aplicación full-stack en C#/.NET 8: ASP.NET Core MVC (vistas Razor) + Web API + SignalR para actualizaciones en tiempo real + EF Core (SQLite).

## Cómo ejecutarlo
1. `dotnet restore`
2. `dotnet run --project InventoryHub.Web`
3. Abre `https://localhost:7080`
